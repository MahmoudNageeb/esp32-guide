📊 ADC — قراءة الجهد (Analog → Digital)

بياخد جهد analog من 0 لـ 3.3V ويحوله لرقم. الدقة 12-bit → قيمة من 0 لـ 4095.

0V → 0  |  1.65V → 2048  |  3.3V → 4095
// قراءة جهد من potentiometer على GPIO34
void setup() {
  Serial.begin(115200);
}

void loop() {
  int raw = analogRead(34);            // 0 → 4095
  float volt = raw * (3.3 / 4095.0); // تحويل لفولت
  Serial.printf("Raw:%d V:%.2f\n", raw, volt);
  delay(500);
}

استخداماته: potentiometer، LDR (ضوء)، حساس حرارة، أي حساس بيطلع جهد متغير.

🔊 DAC — إخراج جهد حقيقي (Digital → Analog)

العكس — بيطلّع جهد analog حقيقي ثابت. اتنين بس: GPIO25 و GPIO26. الدقة 8-bit → من 0 لـ 255.

0 → 0V  |  128 → ~1.65V  |  255 → 3.3V
// إخراج جهد analog حقيقي على GPIO25
void setup() {}

void loop() {
  dacWrite(25, 0);    // 0V
  delay(1000);
  dacWrite(25, 128);  // ~1.65V
  delay(1000);
  dacWrite(25, 255);  // 3.3V
  delay(1000);
}

استخداماته: توليد صوت / موجة sine، التحكم في جهد تماثلي حقيقي.

📐 PWM — تقليد الـ Analog بالنبضات

ده مش جهد حقيقي! بيشغّل ويقفل البن بسرعة جداً، والتحكم في نسبة وقت التشغيل (duty cycle). متوسط الجهد بيبان كأنه analog. أي GPIO يقدر يعمله.

// التحكم في سطوع LED — Arduino Core v3.0+
const int led = 16;

void setup() {
  ledcAttach(led, 5000, 8); // pin, 5kHz, 8-bit
}

void loop() {
  for (int d=0; d<=255; d++){ ledcWrite(led,d); delay(8); }
  for (int d=255; d>=0; d--){ ledcWrite(led,d); delay(8); }
}
النسخة القديمة (Core v2.x) 
ledcSetup(0, 5000, 8);   // channel, freq, res
ledcAttachPin(16, 0);   // pin, channel
ledcWrite(0, duty);       // channel, value

استخداماته: سطوع LED، سرعة موتور، زاوية servo، تشغيل صوت بسيط.

🛠️ مشاريع عملية

1. ديمر LED بالـ Potentiometer ADC + PWM

تلف الـ potentiometer فيزيد/يقل سطوع الـ LED. بيجمع قراءة ADC مع تحكم PWM.

Potentiometer middle → GPIO34
Potentiometer sides → 3V3 & GND
LED + → resistor 220Ω → GPIO16
LED − → GND
const int pot=34, led=16;
void setup(){ ledcAttach(led,5000,8); }
void loop(){
  int raw=analogRead(pot);          // 0-4095
  int duty=map(raw,0,4095,0,255); // 0-255
  ledcWrite(led,duty);
}

2. صفّارة نغمة متغيرة DAC

توليد موجة sine حقيقية على سماعة/buzzer بالـ DAC.

Buzzer + → GPIO25 (DAC1)
Buzzer − → GND
// موجة sine على DAC
void setup(){}
void loop(){
  for(int i=0; i<360; i++){
    int v=128+127*sin(i*3.14159/180);
    dacWrite(25, v);
    delayMicroseconds(50);
  }
}

3. تحكم في Servo PWM

تحريك ذراع servo motor بين 0° و 180° باستخدام مكتبة ESP32Servo.

Servo signal (أصفر) → GPIO18
Servo + (أحمر) → 5V
Servo − (بني) → GND
#include <ESP32Servo.h>
Servo myServo;
void setup(){ myServo.attach(18); }
void loop(){
  myServo.write(0);   delay(1000);
  myServo.write(90);  delay(1000);
  myServo.write(180); delay(1000);
}

4. مفتاح لمس (Touch) Touch + GPIO

لمس سلك متوصل بـ GPIO4 يشغّل LED — من غير زرار فيزيائي.

سلك مكشوف → GPIO4 (Touch0)
LED + → resistor 220Ω → GPIO2
LED − → GND
const int touchPin=4, led=2;
void setup(){ pinMode(led,OUTPUT); Serial.begin(115200); }
void loop(){
  int t=touchRead(touchPin); // أقل = لمس
  Serial.println(t);
  digitalWrite(led, t<40 ? HIGH : LOW);
  delay(100);
}

❓ أسئلة شائعة

إزاي أبرمج الـ ESP32 لأول مرة؟

نزّل Arduino IDE → من Boards Manager ثبّت حزمة esp32 by Espressif → اختار البورد ESP32 Dev Module → وصّل الكابل واختار الـ COM port → اضغط Upload. لو علّق عند Connecting... اضغط زرار BOOT على البورد لحد ما يبدأ الرفع.

ليه الكود مبيترفعش وبيقولي "Failed to connect"؟

٣ أسباب شائعة: (1) كابل USB شحن بس من غير داتا — غيّره. (2) محتاج تثبّت درايفر CP2102 أو CH340 حسب البورد. (3) اضغط واستمر على زرار BOOT وقت ما يبدأ الرفع وسيبه لما يبدأ الـ writing.

الفرق بين 3V3 و 5V (VIN) فين أوصّل إيه؟

الـ 3V3 هو جهد تشغيل الشريحة — وصّل عليه الحساسات اللي بتشتغل 3.3V. الـ 5V/VIN بيجي من الـ USB — استخدمه لتغذية البورد من بطارية، أو لتشغيل servo و LEDs اللي عايزة 5V. ⚠️ بنات الـ GPIO نفسها 3.3V بس — متدخلش عليها 5V غير عن طريق divider أو level shifter.

أنهي بنات أقدر أستخدمها بأمان من غير مشاكل؟

أأمن البنات للاستخدام العام: GPIO 4, 5, 16, 17, 18, 19, 21, 22, 23, 25, 26, 27, 32, 33. ابعد عن 6-11 (Flash) و الـ strapping pins (0, 2, 12, 15) وقت البوت، و34-39 للقراءة فقط.

أوصّل كام LED أو موتور على البورد مباشرة؟

كل بن GPIO بيطلّع ~12mA آمنة (40mA أقصى حد). LED صغير عادي ينفع مباشرة مع مقاومة 220Ω. لكن الموتور والـ servo والريليه ممنوع توصلهم مباشرة — استخدم ترانزستور / driver (مثل L298N أو ULN2003) ومصدر طاقة خارجي، وإلا تحرق البن أو تعمل reset للبورد.

إزاي أوفّر بطارية وأخلي البورد ينام (Deep Sleep)؟

استخدم esp_deep_sleep_start() — البورد بينزل استهلاكه من ~80mA لـ ~10µA. تقدر تصحّيه بمؤقّت أو بلمسة على touch pin أو بإشارة على بن. مثال بسيط:

esp_sleep_enable_timer_wakeup(10 * 1000000); // 10 ثواني
esp_deep_sleep_start();
ESP32 ولا Arduino Uno — أختار أنهي للمشروع؟

لو محتاج WiFi/Bluetooth، سرعة عالية (240MHz)، ذاكرة أكبر، أو ADC/DAC → ESP32 بفرق كبير وبسعر قريب. الـ Uno أبسط للمبتدئين وبيشتغل 5V (أسهل مع بعض الحساسات القديمة). للروبوتات والـ IoT الـ ESP32 هو الاختيار.
